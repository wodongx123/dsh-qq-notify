# QQ 通知通道

一套 Windows 上的 QQ 通知方案：**耗时任务完成 → 自动发 QQ 私聊给你**。底层通过本机 NapCat 机器人（小号承担风险，主号零风险）。所有操作可在 DSH 对话内一步完成，唯一需要人工的操作是扫码登录。

## 全新机器一键上手（约 5 分钟）

### 第 1 步：准备一个小号（机器人号）

登一个不会用到的 QQ 账号当机器人。**不需要扫码，只需能接收消息就行。**

### 第 2 步：在 DSH 里说

重启 DSH 后，直接告诉模型：

> `帮我装好QQ通知`

模型会自动执行以下全部操作（无需任何外部脚本）：
- 从 GitHub Releases 下载最新版 NapCat Shell
- 解压 + 安装到本地目录
- 修复 `--no-sandbox` bug
- 从系统 QQNT 复制加密模块（crypto.dll / ssl.dll）——没装 QQ 也行，不影响启动

完成后提示你下一步 👇

### 第 3 步：扫码登录（唯一需要人工操作的步骤）

```bat
qq start                          # 启动 NapCat（隐藏窗口）
```

用【小号】手机 QQ 扫描登录：
- WebUI：http://127.0.0.1:6099/webui
- 或查看 napcat\cache\qrcode.png

登录后说「我的QQ主号改成 940841288」保存配置。以后就自动快速登录了！

## 日常使用（3 种方式）

### 1. 纯 HTML 控制台（双击即用，不依赖 DSH）

**`qq-panel.html`** —— 浏览器双击打开就能用，和 DSH 在线无关：

| 区域 | 功能 |
|---|---|
| 上方 | 在线状态、机器人号 |
| 中间 | 输入消息 → 点「发送」 |
| 下方 | 启动 / 停止 / 重启 NapCat |

### 2. DSH 对话（6 个工具全自动）

| 你说 | 效果 |
|---|---|
| `用QQ发：任务完成了` | 发到主号 |
| `查看当前QQ配置` | 显示所有配置 |
| `我的QQ主号改成 xxx` | 改配置并保存到磁盘 |
| `查一下QQ通道状态` | NapCat 是否在线 |
| `启动QQ通知` / `重启NapCat` | 后台启停管理 |
| `帮我装好QQ通知` | **自动下载+安装+修复** |

### 3. 命令行

```bat
qq send "消息"    qq status    qq start / stop / restart / logs    qq autostart on
```

## 配置

方法一：DSH 里对我说  
- 「查看当前QQ配置」→ 看所有配置  
- 「QQ主号改成 xxx」→ 自动写文件并保存

方法二：编辑 `napcat/qq-notify.config.json`  
```json
{
  "mainQq": "940841288",
  "_说明": "接收通知的主号 QQ。留空或删掉本文件则用内置默认值。"
}
```

## 故障排查

| 现象 | 处理 |
|---|---|
| 部署失败 | 检查网络（需访问 GitHub），确认有 ~500MB 空闲 |
| 收到消息全是 `?` | 已内置修复 UTF-8 编码问题 |
| 页面连不上 | 确认 NapCat 已启动（`qq start`） |
| 发送失败 | 主号先加机器人小号为好友 |
| 机器人掉线 | `qq restart` 或网页点「重启」 |
